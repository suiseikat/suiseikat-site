# 飞牛影视互通

当前适配 fnOS 影视网页客户端 2026-09-10 构建（客户端版本 631）。接口不是公开稳定 SDK，升级飞牛影视后应重新运行互通测试。

## 配置

在网站运行环境设置：

- `FN_MEDIA_ORIGIN`：飞牛服务器完整源地址，例如 `http://192.168.1.107:5666`，不带 `/v`。
- `FN_MEDIA_ADMIN_USERNAME`、`FN_MEDIA_ADMIN_PASSWORD`：影视管理员凭证，仅服务端使用。
- `FN_MEDIA_CREDENTIAL_KEY`：32 字节随机密钥的 64 位十六进制表示。必须备份并一直保留，不能每次部署重新生成；已绑定账户的随机密码以此密钥加密存入网站数据库。

本地配置位于被 Git 忽略的 `.env.local`。迁移时应安全设置这些环境变量，不要把凭证放进前端代码、公开仓库或构建日志。Compose 已声明变量，但本次未部署服务器。

## 使用与权限

管理员将网站用户设为 SVIP 时同步独立影视账户；其他等级或停用会将已绑定影视账户的媒体权限改为 0，不删除账户或影视文件。首次进入也会重试未完成的账户创建。

右下角控制中心中，已登录 SVIP 可看到「影视」，进入 `/media` 后点击进入即可自动登录。访客、普通会员、VIP、停用用户都不能访问 `/v` 影视代理，即使手动输入地址。管理员也需要 SVIP 授权，不默认越权。

每位用户使用随机密码的非管理员独立影视账户，当前可查看全部媒体库（`media_permission=2`）。网站账户密码不会交给飞牛。真实影视 token 留在服务端；网页 cookie 为无授权能力的占位值。每个接口、图片、视频片段/Range 请求都重新检查网站会员权限。影视服务器管理、账户修改等接口被网站代理禁止。

如果飞牛在播放响应中返回独立 CDN 或其他域名的媒体地址，需要额外配置受保护的代理；不要把 NAS 管理界面直接暴露到公网。当前局域网源站通过网站服务端访问，不要求访客设备能直接访问内网 IP。

## 测试

启动本地网站后执行 `node --env-file=.env.local scripts/smoke-fn-media.mjs`。该测试只创建并清理本轮临时网站/影视账号，不改变现有用户或媒体库。检查非 SVIP 拒绝、独立账号非管理员、自动登录、库读取、敏感接口拒绝、跨站请求拒绝和撤销授权后拒绝。

本次实测已通过以上接口检查，并在生产预览中验证了海报、分类、搜索及《紫罗兰永恒花园》浏览器内播放（视频正常走时、无播放器错误）。截图位于 `artifacts/ui-review/fn-media-playback.png`。
